# Bounty Plugin

A simple Paper Minecraft bounty plugin written in Kotlin.

## Features

- Set player bounties
- Add to existing bounties
- Remove bounties
- Check player bounties
- Customizable `messages.yml`
- MiniMessage support with HEX colors and gradients
- Reload messages without restarting
- Permission support
- Tab completion

## Commands

```text
/bounty check <player>
/bounty set <player> <amount>
/bounty bet <player> <amount>
/bounty remove <player>
/bounty reload
```

## Permissions

```text
bounty.set
bounty.remove
bounty.reload
```
